# Patterns

`examples/` holds five short, original Strudel patterns to start from and to fill the demo batch (`npm run demo`).

| file | idea | tempo |
|---|---|---|
| `ambient-pad.js` | four blurred chords, a sparse high line, a drone | 60 bpm |
| `house-groove.js` | four-to-the-floor, offbeat bass, two-hit chord stab | 122 bpm |
| `lowkey-breakbeat.js` | lazy broken beat, swung hats, a dorian chord | 88 bpm |
| `arpeggio.js` | eight-step arpeggio that shifts every bar | 110 bpm |
| `wildcard-polymeter.js` | 5 against 4 against 3, euclidean kick | 96 bpm |

**Sounds:** only Strudel's built-in synthesizers: the oscillators `sine`, `triangle`, `square`, `sawtooth`, the noise
sources `white` and `pink`, and the synthesized kick `sbd`. No sample files, no sample banks, nothing downloaded.

Try one without the lab: paste it into the editor at [strudel.cc](https://strudel.cc) and press play.
